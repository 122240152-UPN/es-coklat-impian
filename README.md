# Website Es Coklat Impian – Alun-Alun Kidul Yogyakarta

Website profil UMKM/gerai berbasis template Instant Bootstrap yang telah disesuaikan dengan identitas Es Coklat Impian.

## Menjalankan website

1. Ekstrak folder `Instant` dari ZIP.
2. Buka folder `Instant` di Visual Studio Code.
3. Buka `index.html` menggunakan ekstensi Live Server, atau klik dua kali `index.html` untuk melihat versi statis.
4. Pastikan koneksi internet aktif agar Google Fonts, foto dokumentasi, dan peta Google Maps dapat dimuat.

## Fitur yang tersedia

- Navigasi responsif untuk desktop dan ponsel.
- Profil usaha, ringkasan sejarah, dan linimasa.
- Kartu menu dengan filter kategori.
- Struktur jabatan operasional sebagai rancangan studi kasus.
- Galeri foto dengan tautan ke sumber foto.
- Peta Google Maps dan tautan petunjuk arah.
- Formulir pesanan yang menyiapkan pesan WhatsApp.
- FAQ, tautan telepon/email, dan tombol kembali ke atas.

## Catatan data

- Informasi sejarah merek dirangkum dari Portal Berita Pemerintah Kota Yogyakarta.
- Informasi menu dan karakter produk dilengkapi pemberitaan RRI pada 5 Agustus 2026.
- Alamat, kontak, dan jam operasional pada profil lokasi dirujuk dari listing publik outlet. Jam dapat berubah dan perlu dikonfirmasi sebelum kunjungan.
- Struktur organisasi pada website adalah rancangan pembagian peran untuk kebutuhan studi kasus. Nama personel tidak dicantumkan karena belum tersedia data nama yang terverifikasi.
- Harga mulai Rp8.000 merupakan informasi yang diberitakan RRI pada 10 Agustus 2026, bukan jaminan harga terkini.
